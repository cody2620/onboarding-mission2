## 최종 결과물
1. 동작하는 퀴즈게임
* 퀴즈 출제, 등록, 목록, 점수확인, 종료 화면출력
* 퀴즈 풀기, 퀴즈 추가, 퀴즈목록, 점수확인 기능 동작
* 해당 주제의 퀴즈가 5개 이상 포함
* 프로그램을 종료하고 다시 실행해도 추가한 퀴즈와 최고 점수 유지(파일 저장)

2. 코드 구조
* 최소 2개 이상의 크래스 정의(ex. Quiz, QuizGame)
* 기능별로 메서드 분리(입력처리 / 게임 진행 / 저장 로직)
* 데이터는 프로젝트 루트의 state.json에 utf-8 인코딩으로 저장하고 불러온다.

3. 깃허브 저장소
* 프로젝트 코드 깃허브에 업로드
* 최소 10개 이상의 의미 있는 커밋 존재
* 최소 1회 이상의 브랜치 생성 및 병합(checkout, merge) 기록 존재
* clone과 pull을 각각 1회 이상 사용한 기록
* 리드미에 아래 항목 포함
  - 프로젝트 개요
  - 퀴즈 주제 선정 이유
  - 실행 방법
  - 기능 목록
  - 파일 구조
  - 데이터 파일 설명(state.json 등)
